Mark each tee, any dogleg turning points along the line of play, then the centre of the green. Lengths run tee → dogleg points → green centre, measured flat.

For best accuracy: turn on Precise Location, use a Long fix standing still in the open, set Re-mark to Average and mark each point again on a second visit, then drag the pins onto the exact spot on the satellite map.
